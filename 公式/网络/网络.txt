一、协议
1、802.11协议中的RTS/CTS(Request To Send / Clear To Send)机制并不是在每次传输数据帧时都必须使用，而是一种可选机制。
RTS/CTS主要用于解决隐藏节点的问题，只是在特定场景下才使用。是否使用RTS/CTS取决于数据帧的大小。一般只有当数据帧大小超过RTS阈值的时候
才会启动RTS/CTS机制。对于较小的数据帧，使用RTS/CTS反而会增加额外开销，降低网络效率。在实际应用中，RTS阈值可以根据网络环境进行配置，
甚至可以完全禁用RTS/CTS机制。
802.11数据帧有四种子类型，分别是IBSS、From AP、TO AP、WDS。这里的数据帧F是从笔记本电脑发送往访问接入点AP，属于To AP子类型，
这种帧地址1是RA (BSSID),地址2是SA，地址3是DA。
RA是Receiver Address的缩写，BSSID是basic service set identifier 的缩写，SA是Source Address的缩写，DA是destination Address的缩写.
802.11 MAC协议采用了碰撞避免CA、载波侦听多址接入CSMA和链路层确认/重传3左手拿个机制来确保数据帧的可靠传输
2、路由协议按照使用范围可以分为域内路由协议Interior Gateway Protocol，IGP 和 域间路由协议External Gateway Protocol EGP，
BGP Border Gateway Protocol是当前互联网中最主要的域间路由协议，用于在不同自治系统之间交换路由信息。
3、OSPF开放最短路径有线协议是一种链路状态路由协议，直接运行在IP层之上，使用IP协议号89去。它不依赖于TCP或者UDP协议。
OSPF是一种广发使用的内部网关路由协议，适用于大型网络，有：支持分层设计，快速收敛、可以处理复杂的网络拓扑、支持大规模网络的路由计算这些特点。
OSPF是典型的链路状态路由协议，维护完整的网络拓扑数据库，使用Dijkstra算法计算最短路径，通过LSA链路状态报告传播路由信息。比距离矢量协议收敛更快。
OSPF使用区域Area的概念进行网络分割，当网络拓扑发生变化时，变化信息仅在受影响的区域内传播，其他区域不会受到影响，减少了路由更新范围，提高了网络的稳定性和可扩展性。
4、DHCP动态获取IP地址的过程需要遵循一定的转移状态顺序：
（1）初始状态，客户机启动时的第一个状态，此时会广播DHCP DISCOVER消息寻找DHCP服务器
（2）选择状态：客户机收到一个或多个DHCP服务器的DHCP OFFER消息后进入选择状态，从中选择一个服务器。
（3）请求状态：客户机选定服务器后，向该服务器发送DHCP Request 消息，请求分配指定的IP地址
（4）绑定状态：收到服务器的DHCP ACK确认消息后，客户机进入绑定状态，获得IP地址的使用权。
5、带外传输和带内传输区别在于，带外传输：控制信息和数据使用不同的通道传输。带内传输：控制信息和数据在同一个通道传输，FTP采用的是带外传输是其重要特征之一，使其文件传输过程更加可靠和高效。
6、DNS协议属于应用层协议，端口号是53，DNS既可以用UDP传输也可以使用TCP进行传输。
7、文件传输协议是应用层上的协议
8、运行STP协议后可以避免交换机之间存在的环路。STP生成树协议用于解决交换机之间环路问题。当网络中存在冗余链路时，STP通过阻塞特定端口来创建一个无环路树形拓扑结构，同时保持网络的冗余备份能力。
9、（1）CSMA/CD协议中要求发送站点在传输数据帧时能够检测到可能发生的冲突，必须保证数据帧的传输时延至少是信号在介质上传播时延的2倍，这是因为：
最坏情况下，当发送站点刚发送完数据的最后一位时，远端站点也发送数据，这是冲突信号需要传播回发送站点。
信号从发送端到接收端需要1个传播延迟，冲突信号从冲突点返回到发送端又需要1个传输时延，所以总共需要2个传播时延才能检测到冲突。
如果数据帧传输时延小于2倍传播时延，发送站点可能在检测到冲突之前就已经发送完整个数据帧，这样就无法及时发现并处理冲突。
（2）CSMA/CD（载波监听多路访问/冲突检测）协议是一种重要的介质访问控制协议。CSMA/CD是一种争用型的介质访问控制协议。在该协议中，各站点需要竞争使用公共信道，没有中心控制节点来协调传输。
在OSI参考模型中，LLC逻辑链路控制子层位于MAC子层之上。当数据从上层传输到下层的时候LLC帧会被分装在MAC帧的数据单元部分。这是数据封装的标准过程。
CSMA/CD最初是为总线型以太网设计的，特别适用于总线型网络。因为在总线型网络中，所有节点共享同一个传输介质，正好使用使用载波监听和冲突检测机制。
（3）这个协议的哦你工作原理是：发送数据前先监听信道（载波信道），如果信道空闲则发送数据；如果发生冲突则立即检测到（冲突检测），停止发送并等待随机时间后重试。这种机制使得CSMA/CD特别适合总线型网络环境。
10、网关协议可以分为内部网关协议IGP和外部网关协议EGP。BGP Border Gateway Protocol边界网关协议是当前互联网中最主要的外部网关协议，用于在不同自治系之间交换路由信息。
11、ATM Asynchronous Transfer Mode异步传输模式信元由53个字节组成，其中包括5个字节的信头和48个字节的信息载荷。是一种面向连接的快速分组交换技术，建立在异步时分复用基础上，并使用固定长度的信元，支持包括数据、语音、图像在内的各种业务的传送。
12、TCP是面向连接的，在传输数据前要先建立三次握手的连接，UPD是无连接的，发送数据前不需要建立连接。TCP是面向字节流的协议，它将应用层数据看作一串结构的字节流。
UDP是面向报文的，应用层交给UDP多长的报文，UDP就照样发送，不会进行拆分和合并操作。
只有TCP具有拥塞控制机制，通过慢启动、拥塞避免、快重传和快恢复等算法来实现。UDP没有拥塞机制，它不会根据网络状况调整传输速率。
13、RIP是一种分布式的基于距离向量的路由选择协议，通过UDP报文来交换路由信息。OSPF是一个内部网关协议，不使用传输协议，而是直接使用IP报封装它的数据。BGP是一个外部网关协议，用TCP封装它的数据。
距离矢量路由协议具有两个特征：（1）周期性地向邻居路由器发送完整的路由表进行更新，（2）采用分布式的方法，通过逐跳计算来确定到达目的网络的最优路径。

15、IP报文头的TTL Time To Live字段是一个很重要的设计，路由器在正常情况下不应该收到TTL=0的报文，因为当TTL=1的报文到达路由器的时候，
路由器将TTL减1变为0后会丢弃该报文，并向源主机发送ICMP超时信息。
TTL的主要设计目的就是防止IP数据报在网络中无限循环转发。如果网络中出现路由环路，没有TTL机制的话，数据包会一直在环路中传输，浪费大量带宽资源。
TTL字段在IP头部占8位，最大值是255.TTL值只会在经过路由时才会减1，而不是经过所有网络设备都减1.集线器Hub和交换机LAN Switch工作在物理层和
数据链路层，不会处理或修改IP报文头中的TTL值。只有路由器在网络层转发IP报时才会将TTL减1.
这体现了TTL作为一种网络层控制机制的重要作用，既能防止路由环路，又能在故障时即使终止报文传输。

16、1024-65535是动态端口范围，其中1024-49151是注册端口Registered Ports，主要分配给一些应用程序，49152-65535是动态/私有端口，供临时分配使用。
17、ARP协议是实现IP地址到MAC地址映射的关键协议，当一台计算机需要知道目标IP地址对应的MAC地址时，会发送ARP广播请求。这个广播会发送到该网段内的所有主机，
形式为“谁拥有这个IP地址，请回答你的mac地址”。ARP请求必须是广播形式，而不是单播形式。因为发送方并不知道目标主机的MAC地址，所以无法进行单播通信。
ARP响应是单播形式，而不是广播。因为此时响应方已经知道请求方的MAC地址，没必要向整个网段广播。当拥有目标IP的主机收到ARP请求后，会以单播的形式直接响应给请求方，
告知自己的MAC地址。这样可以减少网络中不必要的流量。
18、网络协议的三个主要要素是语法、语义和定时。语义Syntax规定了数据的格式和信号电平等规则，定义了协议中使用的数据格式、结构以及编码方式。
语义Semantics规定了对各类控制信息进行解释的方法，定义了需要发出何种控制信息、完成什么动作以及做出何种响应等。
定时Timing规定了协议执行中各种事件发生的时序关系，包括速度匹配、同步和排序等功能。
19、帧中继是一种面向连接和可靠的数据链路层协议。作为一种高效的数据传输技术，具有以下特点：
（1）在数据传输前需要建立虚电路连接
（2）通过DLCI数据链路连接标识符来标识不同的虚电路。
（3）保证数据按需达到目的地。
（4）可靠性，具有差错检测功能，提供流量控制机制，可以进行拥塞控制。
帧中继通过简化协议栈，取消纠错和流量控制等机制，大大提高了传输效率，这也是它能够广泛应用的主要原因。
20、在滑动窗口协议中，发送窗口大于1而接收窗口等于1的情况下对应的是连续重发协议Go-Back-N。这种协议的特点是：
发送方可以连续发送多个帧，不需要等待每个帧的确认就可以发送下一个帧。接收窗口等于1意味着接收方必须按照顺序接收数据帧，如果收到的不是期望的下一个帧，就会
丢弃该帧并等待正确的帧。当发生错误时，发送方会从最早未被确认的帧开始重新发送所有后续帧。

21、VXLAN是虚拟可扩展局域网Virtual Extensible Local Area Network，在云计算场景中解决了VLAN ID不足和虚机漂移这两个核心问题。
传统VLAN只有12位标识符，最多支持4096各VLAN ID，在大规模云计算数据中心环境下远远不够用。VXLAN采用24位标识符，可以支持约等于1600万个网络标识，
很好地解决了VLAN ID资源不足的问题。VXLAN通过在现有的物理网络上构建overlay网络，支持虚拟机在不同物理服务器之间的灵活迁移，且保持网络配置不变，
这对云计算环境下的资源调度和负载均衡非常重要。

22、MAC Media Access Control 协议作为以太网数据链路层的核心协议提供的是无连接不可靠服务
23、ICMP Internet Control Message Protocol是互联网控制报文协议，主要用于网络诊断和差错控制。ICMP可以报告多种网络差错情况，
如目的不可达、参数错误、重定向等。当路由器或者主机遇到这些情况时，会向源主机发送ICMP差错报文。
ICMP报文可用于拥塞控制（如源抑制消息）和路由控制（如重定向消息），帮助网络进行流量管理和路径优化。
总的来说，ICMP是一个网络层控制协议，主要功能包括网络探测、差错报告、拥塞控制和路由控制，但不具备差错纠正能力。这些功能使得ICMP成为网络诊断和管理的重要工具。
24、TCP报文长度的确定主要取决于对端的接收能力和网络状况，这体现了TCP协议的自适应性和可靠传输特性。对端的接收窗口大小决定了可以发送的数据量，而
网络的拥塞状况也会影响TCP报文端的长度选择。

二、连接
1、TCP建立连接和断开连接过程中的状态变化是遵循固定流程的。

（1）TCP客户端的典型状态转换过程
a.SYNC_SENT:客户端发送SYN请求建立连接后的状态

三、网络层
1、在传输层进行拥塞控制时，重传策略和流控制策略是两种主要且有效的方法。
重传策略：在网络发生拥塞导致数据包丢失时，发送方通过重传机制可以确保数据的可靠传输。
重传可以基于超时或者收到重复确认来触发，这是TCP协议中重要的拥塞控制机制。
流控制策略：流控制可以根据网络状况动态调整发送速率，防止发送方发送速率过快导致网络的拥塞。通过滑动窗口机制，确保接收方能够正常处理接收到的数据。
2、在网络层防止流量拥塞可以采用子网内部的虚电路于数据分报策略，分组排队和服务策略、分组丢弃策略 、路由算法和分组生成管理
3、在数据链路层可以采用：重传策略、乱序缓冲策略、确认策略和流控制策略。
4、在网络层采用数据报服务时，每个分布都是独立进行传输的，没有固定的传输路径。数据报服务的特点就是分组独立传输，每个分组可能选择不同的路径到达目的地，这就要求每个分组都要进行路由选择。
5、计算机网络通信的字节序，在X86平台使用小段字节序，网络传输采用的是大端字节序，在发送的时候需要进行字节序的转换。

五、硬件
1、网桥是工作在数据链路层的网络设备，主要用于连接和扩展局域网。它通过识别数据帧中的mac地址来决定转发、过滤或者丢弃帧，从而实现不同网段
之间的通信。
2、当交换机接收到一帧数据，如果在mac地址中找不到目的MAC地址对应的端口信息，交换机会次啊用泛洪Flooding的方式处理，即将该帧转发到除接收端口
之外的所有其他端口。
3、路由权是路由协议衡量路由优劣的核心指标，它代表了从源节点到目标节点的路径质量。路由权通常根据多个因素综合计算得出，包括跳数、带宽、延迟、可靠性等。
路由协议会选择路由权值最优的路径作为最佳路由。
4、路由器R因为拥塞丢弃IP分组，此时R可向发出该IP分组的源主机发送的ICMP报文件的类型是源抑制。源抑制报文的主要作用是进行流量控制，当路由器或者目的主机由于负载过重而无法征程处理分组时，通过发送源抑制报文
通知源主机降低发送速率，这样可以缓解网络拥塞状况。
5、（1）转发器和集线器都是物理层设备，用于扩展局域网的物理范围。转发器对信号进行放大和转发，集线器用于连接各个网段。
（2）网桥工作在数据链路层，识别MAC地址并根据MAC地址进行数据帧转发。
以太网交换机也工作在数据链路层，交换机本质是一个多端口网桥，通过MAC地址进行数据帧的转发，属于数据链路层的设备
（3）路由器是网络层的设备，通过IP地址进行路由选择和转发，用于连接不同的网络。路由器能够隔离广播，实现不同网络之间的互联。
六、网络攻击
1、典型的DDOS攻击有SYN Flood、NTP放大攻击和CC攻击
SYN Flood攻击者发送大量的TCP SYNC请求，但不完成三次握手，导致服务器资源耗尽。这会使得服务器无法处理正常用户的连接请求。
CC攻击，Challenge Collapsar攻击，通过模拟正常用户的HTTP请求，创建大量的连接占用服务器资源，使服务器无法响应正常请求。
NTP放大攻击，利用NTP服务器的monlist功能，攻击者伪造受害者IP发送请求到NTP服务器，由于响应包比请求包大得多，可以产生流量放大效果，耗尽目标宽带。

七、数据
1、数据报是一种无连接的分组传输方式，数据报的操作特点主要是独立分组传输、动态路由选择、不建立虚电路。
数据报方式下，每个分组都携带完整的地址信息，包括源地址和目的地址，使其能够独立传输和处理。数据报方式是一种无连接服务，不需要在传送前建立虚电路，
每个分组独立选路。由于数据报采用动态路由选择，网络节点需要根据当前网络状况为每个到达的分组单独做出路由决策。
总的来说，数据报方式的主要特点是：分组独立船速、无需建立连接、动态路由。正是因为这种独立传输的特性，分组到达目的地的顺序是不正确的，可能会乱序到达，这也是

区别于虚电路方式的重要特征。
2、IP数据包在传输过程中，由于网络的复杂性和MTU最大传输单元的限制，确实可能发生分片。IP数据包可能在传输过程中发生分片，但是重组只会在目的主机上进行，而不会在中间路由器上进行重组。

4、分组交换技术是一种重要的数据交换方式，具有灵活高效的特点，分组交换技术采用存储转发方式。每个节点接收到分组后，先将其完整存储下来，经过差错检测
等处理后再转发到下一个节点。
分组交换是无连接的通信方式，不需要在传输开始前建立端到端的物理连接。每个分组可以独立地选择路由到达目的地。
在分组交换网络中，由于每个分组可以选择不同的路径，到达目的端的顺序可能与发送顺序不同。需要在目的端重新排序才能还原原始数据。
分组交换要求每个分组都携带源地址、目的地址等控制信息，使网络节点能够根据这些信息进行独立的路由选择。
