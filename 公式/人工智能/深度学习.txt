一、感受野计算
感受野是某一层的一个神经元，在输入图像上“能看到的”区域大小。
记号：
Rl-第l层的感受野大小
Jl-第l层相邻两个神经元在输入上的间距jump/stride in input
Sl-第l层的步幅，layer stride
初始化输入层：
R0=1， J0=1
递推公式：对于第l层：
卷积核大小：Kl
步幅：Sl
空洞率：Dl
1、jump更新
    Jl=J(l-1)*Sl
2、感受野更新
    Rl = R(l-1) + (Kl - 1) * dl * j(l-1)
池化层 = 特殊的卷积层，无参数，直接带入
例子
       K    S   D   J   R
输入层  -    -   -   1   1
第一层  3    1   1   1   3
表示第一层是一个3*3的卷积核，stride为1
J1 = J0 * S1 = 1 * 1 = 1
R1 = R0 + (3 - 1) * 1 = 3

参数个数 = ChannelOut * ChannelIn * KernelHeight * KernelWeight + ChannelOut

三、Transformer
1、在自回归Transformer的长序列生成推理中，复用历史Key/Value的缓存是优化标准实践。它通过缓存先前时间步的Key和Value张量，避免在每个新token
生成时重新计算所有历史token的注意力机制，从而显著减少重复计算、提升吞吐量，同时保持数值不变。
2、梯度检查点机制主要用于训练阶段，用于节省内存，但是会增加计算时间，在推理过程中，无法为减少重复计算。
3、在Transformer的自注意力机制中，输入序列长度为N，隐藏层维度为d。计算包括线性投影和注意力矩阵计算。线性投影的复杂度为O(N*d^2),但是注意力矩阵
（QK^T）的计算复杂度为O(N^2*d)

四、梯度问题
1、在混合精度训练FP16/BF16，梯度下溢是指梯度值过小，在低精度下变为0，导致数值不稳定。动态Loss Scaling通过自动缩放损失值来放大梯度，
防止其在方向传播中下溢，是解决该问题最直接且通用的方法。
动态损失缩放，如pyTorch的GradScaler通过自动调整损失缩放因子，放大损失值和梯度，避免梯度在FP16精度下发生下溢，从而保持训练稳定。


五、DropOut
1、标注DropOut
训练时候，每个神经元以概率p被丢弃，输出设为0，以1-p的概率被保留。
推理时，为了获得确定性的输出，需要平均所有可能的自网络，这等价于使用整个网络，但是每个神经元的输出乘以1-p
2、Inverted Dropout改进
Inverted Dropout将缩放操作移动到训练阶段，训练时候，对保留的神经元的输出直接除以1-p。推理时候，直接使用原始输出，无需任何缩放，直接进行前向传播。

六、RNN
1、当RNN的Loss震荡过大时，可以在训练时设置阈值，当梯度大于阈值的时候直接截断！！！防止大幅震荡。
2、RNN中使用梯度剪裁主要作用是在训练过程中限制梯度的大小，防止梯度爆炸问题，在RNN训练中非常常见，因为序列数据的时间步依赖（如长期依赖）会导致梯度
急剧增大。
3、当使用LSTM处理长序列时，引入Peephole连接机制最能有效缓解长期依赖遗忘的问题。Peephole连接机制，通过让门控单元访问细胞状态来更精确控制记忆和
遗忘，能有效缓解长期依赖问题。
七、归一化
1、在深度学习模型的推理部署阶段，Batch Normalization层计算输入特征的均值和方差时，使用训练过程中积累的移动平均统计量 !!!!这是因为在训练阶段，
Batch Normalization 使用当前批次的统计量进行归一化并更新移动平均，在推理部署阶段，由于输入批次可能较小或者不一致，使用移动平均统计量能够保证
输出的一致性和稳定性。
2、BatchNormal特点：
（1）对每个通道单独进行归一化
（2）统计量（均值、方差）是在batch、height和width维度上计算
（3）每个通道只需要一个均值和一个方差值。
3、batch size的大小会影响梯度估计的精度，在训练深度学习模型时，较大的batch size能够提供更准确的估计，因为：
（1）更大的数据样本：较大的batch size 意味着每次计算梯度时使用更多的训练样本。样本数量越多，计算得到的梯度越接近整个数据集的真实梯度。
这样就减少了随机性带来的梯度波动
（2）统计学原理：根据大数定律，样本量越大，样本统计量越接近总体参数；较大的batch size 提供了更好的梯度期望估计；降低了单个样本异常值堵塞影响。
（3）但是需要注意：过大的batch size 会增加。
4、对于形如φ(WX+b) 形式的神经网络，BN更加倾向于应用在输入WX+b上而非应用在X上，有以下原因：
（1）消除权重W的尺度变化对下一层输入分布的影响，使得激活函数输入稳定，
（2）加速收敛，梯度幅度不受W的缩放影响，可以设置更大学习率
（3）避免激活函数饱和：标准化后输入分布在零附近，梯度较大。
（4）BN的可学习参数能保留网络的表达能力，放在WX+b之后最直接有效
5、BN不适用于循环神经网络
5、、Layer Normaization 适用于循环神经网络
Pre-LN使得每一层的输出范数更加稳定，缓解了梯度消失/爆炸问题，从而支持训练更深层的网络。Pre-LN结构的主要优势在于将归一化置于残差连接之前，这
使得每一层的输入分布更稳定，从而减少梯度消失或者爆炸风险，并支持训练更深层次的网络。

八、知识蒸馏
1、知识蒸馏的核心目标之一就是通过将大模型的知识迁移到小模型，显著减少小模型的参数量和计算复杂度，从而降低存储和部署成本。
2、加速模型的推理速度，小模型由于参数更少、结构更简单，推理速度通常比教师模型更快，尤其适用于移动设备、边缘计算等资源受限制场景。
3、提高模型的预测精度。知识蒸馏通过模仿教师模型的输出分布（软标签）和中间层特征，使得学生模型在保持轻量化的同时，尽可能接近甚至超过
教师模型的预测精度。
4、增加温度参数会使得模型更加柔性，温度过高可能会导致模型输出过于模糊，丢失一些重要信息。虽然可以提高模型的泛化能力，但是不一定会提高模型的鲁棒性。
5、在知识蒸馏框架中，教师模型的主要作用是通过其软标签输出（通常包含温度缩放）提供更丰富的类别间相似信息，如类别间的概率分布和相似性关系，从而
帮助学生模型学习泛化能力。

九、残差网络 Resnet
1、残差网络的跳跃连接主要解决了深度学习中难以学习恒等映射而导致的性能退化问题。当网络加深时，模型优化困难，难以直接将输入映射到输出即恒等映射，
导致训练和测试准确率下降，称为性能退化。
2、跳跃连接通过引入残差学习Residual Learning，使网络能轻松学习恒等映射，如果输入与输出维度相同，则直接跳过某些层，从而有效缓解该问题。

十、鞍点
1、在深度学习模型的损失函数优化过程中，鞍点Saddle Point的核心特征是：梯度为0，但是Hessian矩阵包含正特征值和负特征值，这表明该点既不是局部最小值
也不是局部最大值，而是鞍点。
2、鞍点和损失函数的关系，鞍点可能位于不同损失值水平，且核心不是局部最小值的分布。

十一、生成对抗网络
1、训练中常见的模式崩溃 Mode Collapse问题，本质是指：生成器只能生成少数几种类型的样本，无法为覆盖真实数据的所有模式。无法捕捉真实数据分布的
全部多样性，只能生成有限类型的样本。

十二、自然语言处理
1、小红在进行自然语言处理生成任务时，出现了生成文本大量重复的威尼托可以采用以下手段解决
（1）引入覆盖率机制，通过考虑已经生成内容的情况。
（2）使用束搜索，可以在一定程度上解决文本生成重复问题，维护多个候选解。
（3）使用n-gram阻塞，防止生成相同的n-gram，降低重复可能性。

十三、优化算法
1、AdaGrad 和 RMSProp
AdaGrad 和 RMSProp是深度学习中常使用的的优化方法。
AdaGrad在处理凸优化的问题上相较于非凸优化效果表现更好。在凸优化的问题上，通常能够快速收敛，在面对非凸优化的问题时，学习轨迹可能到达了很多不同的结构，
导致在到达凸结构前梯度就变得太小了。
RMSProp优化了AdaGrad中梯度积累的方式，改为以指数加权的移动平均。
对于AdaGrad， RMSProp使用了移动平均引入了一个新的超参数ρ来控制移动平均的长度范围，同时RMSProp引入移动加权衰减机制以后，对于较为较远的
梯度历史权重会大幅降低，这样一方面能够使得学习率处理合理的调整水平，另一方面的区间范围也更加合理。
