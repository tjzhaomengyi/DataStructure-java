这里针对过去的一些固定形式的写法进行统一，以快慢指针为例，在判断是否停止的时候经常遇见while(fast != null && fast.next != null) 和
while(fast.next != null && fast.next.next != null)不一致的写法，我们在path里面统一成前者。
只是在启动的时候位置不同，slow = head,fast = head;或者slow=head,fast = head.next.next;
一、list 快慢指针设置
1、找中点，进行归并排序
slow = head , fast = head.next
while(fast != null && fast.next != null)
2、找中点，判断回文
slow = head; fast = head
while(fast != null && fast.next != null)
3、判断环和环的入口
slow = head; fast = head
while(fast != null && fast.next != null)

二、链表next指针是否在循环中固定
如果while循环中当前节点固定不动，那么可以在内部新建一个next = cur.next
如果像删除链表中的重复节点那道题，cur要随着while往后推，那么就不能固定next，这样会形成旧的指针，直接使用cur = cur.next这样一直往后推就可以了

三、二分问题中的 while(L <= R) 和 while(L < R)
1、什么时候用while(L <= R) ,什么时候用 while(L < R)
while(L < R) 用来“缩小区间”，最终锁定一个答案。在while的过程中逐渐收缩到一个点，找到“最值”或者“边界”
while(L <= R) 用来“查找某个具体的值”，在while的最后一次都要对mid进行一次尝试，就是要通过mid找到某个target.
总之，当我们要找到target是否存在，或者找到target的位置的时候，要使用while(L<=R),并且最终mid就是候选答案，找不到就要退出。
如果要找最小值（旋转数组），找第一个\找最后一个，类似这种问题，使用while(L < R),这种方法，不会跳过答案，肯定最终收敛到一个点，最后不需要判断是否等于某个target，是一个区间的位置的确定。

四、树的问题
1、DFS 和 BFS 的使用场景归纳
DFS：路径问题、子树计算、树结构修改、回溯
BFS：层序遍历、最短路径、按层统计、扩散传播
2、在递归的时候，什么时候返回void， 什么时候返回数值或者节点
返回void，本质是遍历 + 修改状态，比如中序遍历、或者路径的记录，存储在函数外的一个结果变量中
有返回值，本质是用子问题来构建当前的问题，要把当前的结果传递给“上层”，典型的就是合并树、树深度这类问题，前者是返回节点，后者是返回统计数量。
